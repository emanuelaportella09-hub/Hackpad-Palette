# Hackpad-Palette
A Hackpad where you can switch colors on Paint for Windows 11.

I tried to make a keyboard for when I use Paint, to change colors like a real palette.

IT ONLY WORKS FOR PAINT ON WINDOWS 11.
IT WON'T WORK FOR OTHER SOFTWARE.

It was fun to make, and it taught me more about the production process of keyboards. It's really interesting, because out there is a whole community that loves this kind of hardware.

# FEATURES
- 128x32 OLED display
- 16 keys
- Can change colors on Paint on Windows 11

# BOM

16x Cherry MX Switches

1x XIAO RP2040

16x Differently Colored DSA Keycaps

3x M3x16 Bolt

3x M3 Heatset

1x 0.91" 128x32 OLED Display

16x Through-hole 1N4148 Diodes

1x Case.step in PRODUCTION FOLDER needs to be 3d printed

1x Plate.step in PRODUCTION FOLDER needs to be 3d printed
